# 🚀 IT-Репетитор — Сайт для преподавателя информатики

Космический лендинг для частного репетитора по информатике. Подготовка к ЕГЭ, ОГЭ, олимпиадам и обучение программированию на Python и C++.

![Превью сайта](preview.png)

## ✨ Особенности

- 🌌 **Космический дизайн** — мерцающие звёзды, туманности, планета с вращающимся кольцом
- 💎 **Glassmorphism** — полупрозрачные «стеклянные» карточки с эффектом размытия
- 🌈 **Неоновые градиенты** и свечения вокруг кнопок, заголовков и цифр
- 📱 **Полная адаптивность** — от больших мониторов до смартфонов
- ⚡ **Без зависимостей** — чистые HTML, CSS и минимум JS, сайт загружается мгновенно
- 🎨 **CSS-анимации** — мерцание звёзд, парение планеты, блики на кнопках
